# Privacy notice

Caveat Red is designed not to transmit investigation data. The application has no account, API, analytics, telemetry, error-reporting service, source-document upload, or hosted synchronization. Its own records are stored under `caveat-red.workspace.v1` in the browser’s local storage for the site.

Data remains until the user clears it in Caveat Red, clears browser/site data, or deletes the browser profile. It may be included in browser/device backups, exposed on shared devices, available to browser extensions with appropriate permissions, or synchronized by browser/platform features outside the application’s control. Local storage is not encrypted at rest by Caveat Red.

Use Export all investigations for a user-controlled backup. Exports contain the selected user records and should be protected according to the organization’s information-handling policy. Use Settings → Clear all local data to remove Caveat Red records from the current profile after exporting any required backup.

Do not use the app for credentials, privileged communications, or data that your policy prohibits from browser storage. Questions about the product can be filed through the repository’s GitHub Issues; never include sensitive investigation data in a public issue.
