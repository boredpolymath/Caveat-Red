# User guide

1. **Create an investigation.** Give it a clear scope and purpose. The workspace is stored locally in the active browser profile.
2. **Record claims and evidence separately.** A claim is a statement to assess. Evidence is a citation with title, publisher, URL/file reference, observation and capture dates, locator, source type, verification state, assessment, and limitations.
3. **Record a finding carefully.** Include the factual basis, limitations, confidence, severity, likelihood, and specific next action. A finding is a concern to investigate, not a conclusion of wrongdoing.
4. **Link records.** Use the Links action to associate records without copying or deleting the original. Add notes to preserve context.
5. **Ask and answer questions.** Questions can relate to multiple claims, evidence items, or findings. Set ownership and due date only when useful to your local workflow.
6. **Document contradictions.** Create a contradiction from at least two linked records, compare the dated information, record possible explanations, and link the follow-up or finding.
7. **Assess the checklist.** Record a response, notes, owner, and next action. Unknown answers are explicitly incomplete coverage.
8. **Preview a report.** Select only the records that belong in the working report. Review limitations and open questions before exporting Markdown or printing to PDF.
9. **Back up and restore.** Export all investigations as JSON. To test recovery, use Import in a clean browser profile and compare the record count and links.

Definitions: a **claim** is a reported assertion; **evidence** is a reproducible source record; a **finding** is an assessed concern; **confidence** expresses evidence quality separately from priority; a **contradiction** is unresolved tension between records; **resolution** records why a finding changed status and which evidence supports that change.
