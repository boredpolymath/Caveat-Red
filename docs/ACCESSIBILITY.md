# Accessibility statement

Caveat Red targets WCAG 2.2 AA. The interface uses semantic headings, navigation landmarks, labeled controls, visible focus, keyboard-operable dialogs, native form controls, live save/error messages, responsive tables, reduced-motion-respecting browser behavior, and print styles.

Before each release, perform manual keyboard-only testing for all views, dialogs, filters, destructive actions, import/export, and mobile navigation; zoom/reflow at 200% and 400%; and screen-reader testing with a supported browser/screen-reader pairing. Log and resolve blockers before release. Report accessibility issues through GitHub Issues without including private investigation records.
